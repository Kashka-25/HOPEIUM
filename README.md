# HOPEIUM

**A beacon of hope for humanity.**

HOPEIUM is an independent project exploring how hope, compassion, connection and human potential can help us navigate difficult times.

This repository contains the first public-facing website foundation. It is intentionally simple, accessible and easy to build upon.

## First version

- A calm, responsive landing page.
- A clear statement of purpose.
- A small set of guiding principles.
- A gentle invitation to connect.
- No frameworks, build tools, trackers or external dependencies.

## Run locally

Open `index.html` in a browser. The site is plain HTML, CSS and JavaScript, so there is no installation step.

## Project principles

1. **Keep the message human.** Hope should feel real, grounded and shared.
2. **Make it welcoming.** Clear language, generous space and accessible contrast.
3. **Start with the essence.** Build only what serves the purpose.
4. **Grow with care.** Add features when the community and mission genuinely need them.

## Status

Early concept and visual foundation. The wording and future direction should continue to be shaped by the HOPEIUM vision.
